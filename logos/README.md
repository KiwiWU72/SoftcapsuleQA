# 各廠 LOGO 放這裡

把各公司官方網站「媒體／新聞資料（Press kit）」下載的 LOGO 檔，依下列檔名放進這個資料夾，網頁就會自動顯示；沒放的會顯示公司名稱文字。

| 公司 | 檔名（擇一） |
|---|---|
| GELITA | `gelita.png` 或 `gelita.svg` |
| Rousselot | `rousselot.png` 或 `rousselot.svg` |
| PB Leiner | `pb-leiner.png` 或 `pb-leiner.svg` |
| Nitta Gelatin | `nitta.png` 或 `nitta.svg` |
| 東寶生物 | `dongbao.png` 或 `dongbao.svg` |
| Weishardt | `weishardt.png` 或 `weishardt.svg` |
| Roquette | `roquette.png` 或 `roquette.svg` |

建議：透明背景、高度至少 120 px。使用前請確認各公司對 LOGO 使用的規範。
